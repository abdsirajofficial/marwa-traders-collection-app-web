# Marwa Traders — Web & Mobile Frontend Repository

This repository contains both the Desktop/Web management client and the React Native / Expo mobile cash collector application.

## Structure
- `/desktop` — React (Vite + TailwindCSS + Lucide Icons) Desktop Management Portal
- `/mobile` — React Native (Expo SDK 52) Mobile Cash Collection App

## Getting Started

### Desktop App
```bash
cd desktop
npm install
npm run dev
```

### Mobile App
```bash
cd mobile
npm install
npx expo start -c
```
